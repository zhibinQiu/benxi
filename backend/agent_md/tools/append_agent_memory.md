在用户的长期记忆中追加一条笔记。

## When to use
- 用户明确要求「记住」某条信息（如「帮我记住……」「记下来……」）
- 用户希望保存一段文本到自己的长期记忆中供以后回顾

## When NOT to use — 极其重要
- **不得用本工具作为无法执行用户请求时的兜底**。没有能力完成时直接告知用户，不要把请求写入记忆。
- **不得代替其他工具**。应搜索/调用技能时，调用对应工具，不要写入记忆。
- **不得用本工具「假装已完成任务」**。写入记忆不等于完成原始请求。
- **不要记录已执行的工具调用结果**。工具结果已在对话历史中。

## Returns
- 追加成功确认（是否写入 MEMORY.md）
