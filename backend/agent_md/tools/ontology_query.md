查询**本体语义中枢**（非事实库）：理解问题涉及的业务概念、字段映射与查询路径规划。

**使用时机：**
- 用户问"系统有哪些实体类型？"、"组织之间有几种关系？"、"指标有哪些属性？"
- 需要弄清「问的是什么、该查什么、去哪里查、按什么路径查、为什么」时
- 在调用 `kg_query` 前，先通过此工具确认概念与路径

**不使用时机：**
- 用户问具体的实体实例或关系实例（走 `kg_query`）
- 需要直接查业务事实数据（本体只规划，不取数）

**返回：** 概念解析、字段映射摘要、Neo4j/SQL 查询计划说明，以及相关本体 Schema 精简文本。

**参数：**
- `question` (string, 必需): 用户关于本体/业务语义的自然语言问题
