---
name: update_kb_folder
---
更新文档库文件夹的名称或描述。

## When to use
- 重命名文件夹或修改说明

## When NOT to use
- 新建文件夹（用 create_kb_folder）
- 删除文件夹（用 delete_kb_folder）

## Returns
- 更新后的文件夹信息

## Parameters

### scope (optional)
默认 personal。

### folder_id / folder_name (optional)
定位目标文件夹。

### name (optional)
新名称。

### description (optional)
新说明。
