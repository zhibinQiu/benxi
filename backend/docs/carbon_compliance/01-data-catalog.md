# 控排企业碳交易智能策略推荐系统 — 全量数据分类

适用范围：火电 / 钢铁 / 水泥 / 电解铝全国碳市场控排企业。

数据挂载用户维度（`user_id`），企业为用户下多主体档案。

## 一、企业基础静态数据

### 1. 企业主体信息（表 `carbon_enterprises`）

| 数据项 | 必填 | 用途 | 来源 |
|--------|------|------|------|
| 企业名称、统一社会信用代码 | 必填 | 主体标识、台账归档 | 手工录入 / Excel |
| 所属控排行业（power/steel/cement/aluminum） | 必填 | 匹配配额与核算规则 | 手工 |
| 纳入全国碳市场起始年份、履约周期 | 必填 | 区分历年配额、清缴时间 | 手工 |
| 风险偏好（conservative/balanced/aggressive） | 必填 | 控制策略激进程度 | 手工 |
| 年度碳采购预算上限、单笔交易限额 | 必填 | 约束采购规模 | 手工 |
| 企业属性（listed / CBAM / industrial） | 可选 | ESG、碳关税配套策略 | 手工 JSON |

### 2. 行业固定政策参数（`platform_carbon_strategy_settings.industry_params`）

| 数据项 | 必填 | 用途 | 来源 |
|--------|------|------|------|
| 行业配额分配基准线、产能折算系数 | 可选 | 预估免费配额 | 后台配置 |
| 免费配额发放月、结转年限与上限 | 必填 | 结转与持仓规划 | 后台配置 |
| 清缴截止日期（月-日）、逾期罚金 | 必填 | 预警与兜底成本对比 | 后台配置 |
| 电网年度平均排放因子 | 必填 | Scope2 核算 | 后台配置 |

## 二、企业碳排放数据

### 1. 历史已核查排放（表 `carbon_emission_years`）

| 数据项 | 必填 | 用途 | 来源 |
|--------|------|------|------|
| 年度核查总 CO₂e | 可选（可核算推导） | 履约基数 | 核查报告 / 手工 |
| Scope1 化石燃烧、工艺排放 | 必填（核算输入） | 原始总排放 | 手工 / ERP |
| Scope2 外购电力排放 / 外购电量 MWh | 必填 | Scope2 与绿电核减 | 手工 |
| 月度明细 JSON | 可选 | 当年波动预测 | 手工 |
| 历史缺口/富余、当年已用 CCER | 可选 | 策略参考 | 手工 |

### 2. 预测数据（表 `carbon_emission_forecasts`）

| 数据项 | 必填 | 用途 | 来源 |
|--------|------|------|------|
| 履约年预测总排放 | 必填（无核查时） | 当期缺口测算 | 手工 |
| 产能规划、技改减排、生产计划 | 可选 | 中长期策略 | 手工 |

## 三、碳资产台账

### 台账 1：CEA（`carbon_cea_holdings` / `carbon_cea_trades`）

| 数据项 | 必填 | 用途 |
|--------|------|------|
| 分年度免费配额、过期量、成本均价 | 必填 | 履约缺口、出售空间 |
| 预估未来免费配额、可出售上限 | 可选 | 中长期规划 |
| 买卖流水 | 可选 | 持仓成本与台账滚动 |

### 台账 2：CCER（`carbon_ccer_holdings` / `carbon_ccer_trades`）

| 数据项 | 必填 | 用途 |
|--------|------|------|
| 存量、项目类型、签发年、有效期 | 必填 | 合规抵扣 |
| 采购成本、可抵扣有效量 | 必填 | 配比测算 |
| 关联绿证标记 | 可选 | 双重权益拦截 |
| 政策硬约束 | 配置 | 抵扣上限 = 核查排放 × 5% |

### 台账 3：绿电与绿证

直购绿电（`carbon_green_power`，履约核算必填项）：市场化绿电电量、自发自用电量、溢价、合同凭证。

纯绿证（`carbon_green_certs`，ESG 可选）：数量、单价、核销状态、消纳权重目标。**不参与履约核减。**

## 四、碳市场历史基准数据（月度）

| 表 | 用途 |
|----|------|
| `carbon_market_cea_monthly` | CEA 月均价、高低点、时段标签 |
| `carbon_market_ccer_monthly` | 分类型 CCER 月均价 |
| `carbon_market_energy_monthly` | 绿电溢价、绿证价、煤价 |

无需分钟级行情；可由手工维护或可选外站摘要补充。

## 五、政策规则库

存储于 `platform_carbon_strategy_settings`（单例），涵盖清缴、CCER 抵扣、绿电核减、新能源权益二选一、手续费、有偿拍卖收紧规划（integrations/cost/compliance 字段）。后台可改，无需发版改代码。
