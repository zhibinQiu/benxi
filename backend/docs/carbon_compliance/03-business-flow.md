# 业务全流程

## 总链路

企业基础数据录入 → 碳排放 + 碳资产台账同步 → 核算模块计算核查排放与履约缺口 → 市场行情周期判断 → 策略引擎分场景生成多套方案 → 合规校验过滤 → 输出分层推荐报告 → 风险预警推送。

## 步骤 1：基础数据初始化

1. 创建 `carbon_enterprises` 主体（行业、风险偏好、预算）。
2. 导入近 3 年 `carbon_emission_years` 与当年 `carbon_emission_forecasts`。
3. 同步 CEA / CCER / 绿电(绿证) 台账。
4. 系统加载 `platform_carbon_strategy_settings` 与月度行情表。

## 步骤 2：碳排放量核算

公式（`accounting.compute_accounting`）：

- 原始总排放 = Scope1 + 外购电量 × 电网排放因子（若已给 Scope2 也可直接用分项和）
- 可核减电力排放 = 市场化直购绿电电量 × 电网排放因子（纯绿证不计）
- 最终核查排放 = 原始总排放 − 可核减电力排放
- 履约缺口/富余 = 最终核查排放 − 可用免费 CEA
- CCER 合规上限 = 最终核查排放 × `ccer_max_ratio`

## 步骤 3：市场行情周期判断

基于 CEA 月度均价分位与当前月份，输出 `price_band`（low/mid/high）、`time_window`（early/mid/late）、`action_tag`（buy/sell/hold）。

## 步骤 4：策略引擎四维方案

1. 配额买卖（缺口采购 / 盈余出售，结合价格带与清缴紧急度）
2. CEA+CCER 跨品种配比（优先自有 CCER，价差大时外购填满 5%）
3. 直购绿电中长期优化（溢价 vs 少买碳资产节约）
4. ESG 绿证配套（不影响履约，单独展示）

按画像过滤后生成三套方案：最低成本履约、成本优化综合、全维度合规。

## 步骤 5：合规校验

CCER≤上限、过期剔除、绿证与 CCER 双重权益禁止、预算上限、大额拆分建议。不合规动作标记剔除或改写。

## 步骤 6：分层输出

每套方案含：操作时间窗口、建议交易量、总成本、净节约；可导出 Markdown/HTML。

## 步骤 7：风险预警与台账滚动

清缴倒计时、碳价波动、CCER 超限写入 `carbon_alerts` 并可推送站内通知；交易完成后更新台账，次年滚动预测。
